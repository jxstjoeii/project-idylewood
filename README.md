# Project Idylewood

IT upgrade proposal for an accounting firm in downtown Tacoma. This is a team school project. The graded deliverable is one PowerPoint, presented in the last class meeting.

The unrelated "invention / new tool" rubric that was pasted with the assignment is out of scope.

## Client

Accounting company with an office on Pacific Avenue in downtown Tacoma.

- Each employee has a key to the office.
- A building janitor cleans the offices every evening.

## Current state

- 20 PCs running Windows XP, Windows 7, and Windows 10.
- Each workstation has a 17" CRT, a keyboard, and either a PS/2 or USB mouse.
- Each workstation has its own standalone USB inkjet printer. Models vary.
- One leased Xerox multi-function device (fax, printer, scanner). It is not networked.
- One large-format dot matrix printer used to print checks.
- DSL internet from Qwest / CenturyLink.
- Client files are also kept in an offsite storage facility.
- Each employee uses a Hotmail account for work email.
- Digital files live on each PC, or on a flash drive used as backup.
- Many files are still on floppy disks and CDs.

## Goal

Upgrade the systems to current standards. Provide basic small-network infrastructure and server services that give the office access to the internet.

## PowerPoint deliverable

Presented in the last class meeting. Each team gets 15 minutes. Every team member talks.

Required pages:

1. Title page
2. Overview page
3. Equipment descriptions and examples
4. Budget
5. Implementation plan / timeline
6. Lessons learned
7. References
